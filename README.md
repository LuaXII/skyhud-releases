# SkyHUD

Modern, good-looking HUD overlays for Hypixel SkyBlock — slayer tracking & boss mechanics, Garden visitors,
pests and farming, timers, item values and more. Fabric, Minecraft 26.2.

## Install
1. Download the latest **`skyhud-x.y.z.jar`** from [Releases](../../releases/latest).
2. Put it in your `mods` folder together with **Fabric API** for 26.2.
3. Launch the game and type **`/skyhud`**.

## Updates
SkyHUD updates itself: when a new version is out it downloads in the background, checks its SHA-256 against
the `.sha256` file published with the release, and installs when you close the game. You can turn this off in
`/skyhud` → General → *Automatic updates*.

SkyHUD only reads what the game already shows you — no automation.
